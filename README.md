# 因為太怕死，只好派分身去滅世

像素風肉鴿 × 殭屍生存 × 無限捲軸的網頁遊戲。

穿越到魔法、武道與賽博義體並存的未知時代，全城的人都失去理智，把你當成「劣等產物」追殺。絕境中覺醒了怕死系統，拿到開局獎勵《分身術》與一間絕對安全屋——於是你決定：自己絕對不出門，讓分身去打。

## 玩法

- **安全屋**：主頁面。派遣分身、到系統商城抽功法、在功法閣替分身裝備功法。
- **分身出擊**：無限捲軸生存，自動攻擊，撐越久、打越多，帶回的系統點數越多。
- **功法**：15 本（含開局的分身術），分為武道與魔法兩派。分身術的限制是一個分身只能學一本。
- **武器**：分身在野外撿武器，最多 5 把。武器升到 Lv3 會依功法流派覺醒「超凡用法」。
- **手搓機甲**：每次升級，系統有機會隨機附贈機甲部件，撐到六件到齊就能當場組出機甲「怕死一號」。
- **終局**：習得全部功法後，世界首腦會找上門。
- **二周目**：無限流，可同時派出三名分身。

## 操作

| | 電腦 | 手機（橫放） |
|---|---|---|
| 移動 | WASD／方向鍵 | 按住螢幕任意處拖曳 |
| 攻擊 | 自動 | 自動 |
| 暫停 | Esc／P | 右下角「暫停」 |
| 升級選項 | 1～3 或點擊 | 點擊 |

存檔儲存在瀏覽器的 localStorage，換瀏覽器或清除網站資料會遺失進度。

## 執行

不需要安裝任何東西，直接用瀏覽器開啟 `index.html` 即可，也可以放到 GitHub Pages 等任何靜態網站空間。

想要一個可以單獨傳給別人、雙擊就能玩的檔案：

```sh
python3 tools/build_single.py
# 輸出：dist/因為太怕死只好派分身去滅世.html
```

## 專案結構

```
index.html            頁面、樣式、UI 版面
js/data.js            調色盤、像素精靈、功法／武器／敵人資料、劇情台詞
js/gfx.js             繪圖工具、地圖圖塊、過場背景、安全屋、世界首腦
js/game.js            場景、存檔、音效、出擊引擎、功法與武器邏輯、HUD
tools/build_single.py 打包成單一 HTML
```

所有像素圖都是程式即時繪製，沒有外部圖片；字型使用 Google Fonts 的 DotGothic16，離線時會改用系統字型。
